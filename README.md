# Past.io

Past.ioは、パスタのキャラクターが麺を撃ち、壁・床・天井・物体・他プレイヤーへ接続して動く横2DオンラインPvPアクションゲームです。移動ボタンはありません。プレイヤーの移動は麺の接続とマウス操作だけで成立します。

## 操作

| 入力 | 動作 |
|---|---|
| マウス移動 | 麺の照準と、接続中の張力方向を操作 |
| マウス左ボタン長押し | カーソル方向へ麺を射出し、対象に命中した間だけ接続 |
| マウス左ボタンを離す | 麺を解除し、蓄積された物理速度を解放 |
| Esc / EXIT | ルームを退出 |

麺は接続しただけではプレイヤーを対象座標へ移動させません。マウス位置によって麺の長さと張力が変化し、その張力から物理速度が発生します。固定物ではプレイヤー側が動き、箱・ドラム・吊り荷などの可動物では物体側が動き、他プレイヤーへの接続では双方に反作用が発生します。

可動物は速度と重量に応じてプレイヤーへ衝突ダメージを与えます。プレイヤーにはHPがあり、被弾時には短い無敵時間とノックバックが発生します。攻撃ボタンや武器は追加せず、麺で物体を動かしてぶつけることだけを攻撃手段にします。

## ローカル起動

```bash
cd server
npm install
npm start
```

ブラウザで `http://localhost:3000` を開きます。

## マップ

画面内で完結する広い足場列ではなく、太い壁・床・天井、中央の煙突、梁、狭い通路、支点、重量の異なる物体を重ねた横2Dアリーナです。マップ内を自由に移動し、地形・物体・麺・他プレイヤーを組み合わせて対戦します。

## 未実装の仕様

勝利条件、撃破後の扱い、試合時間、武器、スキル、成長要素は追加していません。現在の焦点は、麺を撃つ、接続する、マウスで張力を操作する、対象ごとに物理挙動が分かれる、物体を他プレイヤーへぶつける、というコア部分です。
