# Past.io

Past.ioは、縦に登りながら拾い物を集め、ルーム内のプレイヤーをフックできるオンラインパーティゲームです。

## 操作

| 入力 | 動作 |
|---|---|
| A / D または ← / → | 左右移動 |
| Space | ジャンプ |
| マウス左ボタン長押し | 足場またはプレイヤーへフック。押している間だけ牽引 |
| Exit / Esc | ルームを退出 |

## ローカル起動

```bash
cd server
npm install
npm start
```

ブラウザで `http://localhost:3000` を開きます。

## ゲーム要素

ホームで名前を入力してルームを作成できます。ルームコードを共有すると他のプレイヤーが参加できます。ホストが開始すると、seedから縦型マップ、足場、拾い物、ゴールが生成されます。拾い物は接触で取得し、マップ上の他プレイヤーへもフックを当てられます。
