# Past.io

Past.ioは、パスタの身体を左右へ振りながら、麺フックで足場と他プレイヤーを引き寄せるオンラインパーティゲームです。

## 操作

| 入力 | 動作 |
|---|---|
| A | 左へ移動 |
| D | 右へ移動 |
| マウス左ボタン長押し | 麺フックを伸ばす。足場またはプレイヤーへ接続し、押している間だけ牽引 |
| Exit / Esc | ルームを退出 |

## ローカル起動

```bash
cd server
npm install
npm start
```

ブラウザで `http://localhost:3000` を開きます。

## ゲーム要素

ホームで名前を入力してルームを作成できます。ルームコードを共有すると他のプレイヤーが参加できます。ホストが開始すると、seedから縦型マップ、足場、拾い物、ゴール、上層ほど厳しくなるギミックが生成されます。足場は狭くなり、間隔が広がり、揺れる足場・崩落足場・針足場が増加します。落下時は直前の到達地点へ戻ります。
