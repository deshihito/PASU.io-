# PASU.io

PASU.ioは、シンプルな図形で描くベクター調のパスタ・パーティゲームです。白い皿のような広いアリーナを、黄色い円形パスタが**フック／ハンドだけ**で移動します。

## フック操作

| 段階 | 操作 |
|---|---|
| 1 | クリックで照準方向の不動態・動態オブジェクト・プレイヤーへ麺を飛ばして接続 |
| 2 | 接続中にクリックを押し続け、マウスを動かして張力と移動方向を操作 |
| 解除 | クリックを離す。ウィンドウから離れた場合も解除 |

不動態は壁・床・天井・固定足場など、マップ上の固定矩形です。不動態へ接続すると、張力でプレイヤー自身が動きます。動態は箱やハンマー、銃、石ころなどの可動オブジェクトです。動態へ接続すると、対象物がマウス方向の張力に従って動きます。プレイヤーへ接続した場合は、プレイヤー同士に反作用が発生します。クリック位置までの麺の線分が実際の矩形へ触れた場合だけ接続し、仮想的なアンカー点は生成しません。

フックの最大距離は760ワールド単位、1フレームあたりの最大力は12です。接線方向の操作力も強化しており、軽い銃や石ころだけでなく、重量4.8のハンマーも麺で振り回せます。クリック位置が最大距離を超える場合は最大距離までを判定範囲とし、接続後に距離が上限を超えた場合は自動解除します。

スマートフォンでは、ゲームCanvasのタッチ開始・移動・終了を明示的に処理し、長押し中のテキスト選択、コピー、コンテキストメニューを無効化しています。ゲーム画面以外の名前入力とルームコード入力は通常どおり使用できます。

## PvPオブジェクト

PvPでは、ハンマー、銃、石ころがマップ上に落ちています。道具もフック対象で、麺の張力によって移動させてプレイヤーへぶつけられます。ハンマーは重量4.8、銃は重量0.8、石ころは重量1.2です。衝突速度と重量からダメージとノックバックを計算します。攻撃用の別ボタンや専用アクションはありません。

## 物理テンポ

物理更新は約33ms周期で進み、プレイヤー最大速度18、プレイヤー重力0.68、動態オブジェクト重力0.62、動態オブジェクト最大速度28へ調整しています。オブジェクトの速度減衰も軽くして、フックで引いた道具が勢いを保って振り回せるテンポにしています。

## マップ

マップは現行比で横10倍・縦10倍に拡張した `18000 × 9800` の空間です。モードごとに専用レイアウトを持ち、同じマップを使い回しません。

| モード | マップ | 地形の特徴 |
|---|---|---|
| TAG | SAUCE LOOP | 周回足場、ゲート、追跡用の段差 |
| HIDE | PANTRY MAZE | 天井付きの部屋、縦壁、複数の分岐 |
| FREE | NOODLE PARK | 高低差のある自由な足場とゲート |
| HILL | PARMESAN PEAK | 上へ連続する階段状の登坂ルート |
| PVP | BONK BOULEVARD | 長い闘技場、仕切り、道具の散在 |

固定足場はモードごとに複数の段差・縦壁・狭い通路・囲い・分岐を組み合わせ、さらにseedで散在足場を追加します。描画はCanvasの円・線・矩形・多角形だけで構成し、外部画像素材に依存しません。スポーン地点もモード専用に分け、参加者は既存プレイヤーから180ワールド単位以上離れた空き地点を順に選びます。

ゲーム画面の右上には、固定地形を黄色、道具を赤、プレイヤーを色付きの点、現在の視界を枠線で示すミニマップを表示します。

## ローカル起動

```bash
cd server
npm install
npm start
```

ブラウザで `http://localhost:3000` を開きます。`http://localhost:3000/?demo` では、ルーム作成からゲーム開始までを自動実行します。
