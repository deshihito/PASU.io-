# Past.io

Past.ioは、パスタの身体を左右へ振り、麺フックの反動と牽引で手作りチャンクを突破するオンラインパーティゲームです。

## 操作

| 入力 | 動作 |
|---|---|
| A | 左へ移動 |
| D | 右へ移動 |
| マウス左ボタン長押し | 麺フックを伸ばす。足場またはプレイヤーへ接続し、押している間だけ牽引 |
| Exit / Esc | ルームを退出 |

## ローカル起動

```bash
cd server
npm install
npm start
```

ブラウザで `http://localhost:3000` を開きます。

## ゲームループ

ホームでルームを作成し、コードを共有して参加者を集めます。ホストが開始すると、seedから8種類の手作りチャンクを接続した縦型コースが生成されます。ジグザグ、揺れる足場、崩落、針、狭いガントレット、分岐ショートカットを区間ごとに組み合わせ、上層ほど足場幅・距離・移動速度・危険密度が上がります。

拾い物は安全な足場だけでなく、危険な分岐にも配置されます。落下や針への接触ではスコアを失い、最後に到達したチェックポイントへ戻ります。プレイヤー同士は麺フックで引き寄せたり、引っ張り合ったりできます。
