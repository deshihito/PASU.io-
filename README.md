# PASU.io

PASU.ioは、**シンプルな図形だけで描くベクター調のパスタ・パーティゲーム**です。白い大皿のような広大なアリーナを、黄色い円形パスタが麺フックで転がり、掴み、逃げ、ぶつかります。写実的な質感や複雑な陰影は使わず、白・アルデンテイエロー・トマトレッド・チャコールの4色と、円・線・矩形・多角形でゲーム状態を読み取れるようにしています。

## ゲームモード

| モード | 目的 |
|---|---|
| **TAG / 鬼ごっこ** | 相手に近づき、ソースを渡して追跡を入れ替える |
| **HIDE / 隠れんぼ** | ランドマークと広いマップを使って見つからずに逃げ切る |
| **FREE / フリーモード** | 勝敗を気にせず、皿の上を好きに転がって探索する |
| **HILL / ヒルアンドハイ** | 高い位置を奪い、滞在時間でスコアを伸ばす |
| **PVP / ソース決闘** | 落ちている道具を持ち、動かし、効果を発動してぶつける |

## 操作

| 入力 | 動作 |
|---|---|
| マウス移動 | 麺フックの照準と張力方向を操作 |
| マウス左ボタン長押し | 照準方向へ麺を射出し、地形・物体・他プレイヤーへ接続。PvPでは近くの道具を掴む |
| マウス左ボタンを離す | 麺と掴んでいる道具を解除し、物理速度を解放 |
| Space長押し | PvPで持っている銃などの効果を発動 |
| Esc / EXIT PLATE | ルームを退出 |

麺は固定地形ではプレイヤーを、可動物では物体を、他プレイヤーでは双方を動かします。マップの基本サイズは従来比で**横10倍・縦10倍**です。白い床、黄色い梁、赤いソース缶、フォーク、チーズ、木箱のランドマークを連続させ、広さの中にも方向感覚を作っています。

## PvPインタラクティブオブジェクト

| 道具 | 重量 | 効果 |
|---|---:|---|
| **ハンマー** | 4.8 | 重い速度でぶつかると大ダメージ。持つと動きが鈍くなる |
| **銃** | 0.8 | Spaceで反動を発生させ、狙いと反対方向へ飛ぶ |
| **石ころ** | 1.2 | 軽く滑り、接触時に小さな「BONK」ダメージ |

## ローカル起動

```bash
cd server
npm install
npm start
```

ブラウザで `http://localhost:3000` を開きます。`http://localhost:3000/?demo` では、デモ用にルームを自動作成してゲーム画面へ進めます。

## 構成

クライアントは `docs/index.html`、`docs/style.css`、`docs/game.js` の小さな構成です。サーバーは Node.js と Socket.IO でルーム、モード、マップ、プレイヤー、物理オブジェクトを同期します。ゲーム描画は Canvas によるフラットなベクター描画で、外部画像素材に依存しません。
