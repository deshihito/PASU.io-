# PASU.io

PASU.ioは、シンプルな図形で描くベクター調のパスタ・パーティゲームです。白い皿のような広いアリーナを、黄色い円形パスタが**フック／ハンドだけ**で移動します。

## フック操作

| 段階 | 操作 |
|---|---|
| 1 | クリックで照準方向の不動態・動態オブジェクト・プレイヤーへ麺を飛ばして接続 |
| 2 | 接続中にクリックを押し続け、マウスを動かして張力と移動方向を操作 |
| 解除 | クリックを離す。ウィンドウから離れた場合も解除 |

不動態は壁・床・天井・固定足場など、マップ上の固定矩形です。不動態へ接続すると、張力でプレイヤー自身が動きます。動態は箱やハンマー、銃、石ころなどの可動オブジェクトです。動態へ接続すると、対象物がマウス方向の張力に従って動きます。プレイヤーへ接続した場合は、プレイヤー同士に反作用が発生します。クリック位置までの麺の線分が実際の矩形へ触れた場合だけ接続し、仮想的なアンカー点は生成しません。

フックの最大距離は760ワールド単位、1フレームあたりの最大力は8です。接線方向の操作力を抑えつつ、動態オブジェクト専用の操作係数を2.2にして、道具を振り回せるが飛びすぎない強さにしています。クリック位置が最大距離を超える場合は最大距離までを判定範囲とし、接続後に距離が上限を超えた場合は自動解除します。

スマートフォンでは、ゲームCanvasのタッチ開始・移動・終了を明示的に処理し、長押し中のテキスト選択、コピー、コンテキストメニューを無効化しています。ゲーム画面以外の名前入力とルームコード入力は通常どおり使用できます。

## ゲームモード

| モード | ルール | 勝利条件 |
|---|---|---|
| 鬼ごっこ / TAG | 他プレイヤーへ体当たりしてタッチを取る。 | 先に5タッチ。90秒経過時はタッチ数最多。 |
| 隠れんぼ / HIDE | フックを出さず、速度を止めて隠れ時間を貯める。 | 累計30秒の隠れ時間。90秒経過時は隠れ時間最多。 |
| フリーモード / FREE | 地形を巡り、クラムとレリックを集める。 | 先に20ポイント。120秒経過時は得点最多。 |
| ヒルアンドハイ / HILL | 上部の頂上エリアへ登り、滞在時間を稼ぐ。 | 頂上の累計滞在30秒。120秒経過時は滞在時間最多。 |
| PvP / PVP | フックで道具と相手を動かし、HPを削る。 | 最後まで残ったプレイヤー。180秒経過時は得点最多。 |

## PvPオブジェクト

PvPでは、ハンマー、銃、石ころがマップ上に落ちています。道具もフック対象で、麺の張力によって移動させてプレイヤーへぶつけられます。ハンマーは重量4.8、銃は重量0.8、石ころは重量1.2です。衝突速度と重量からダメージとノックバックを計算します。攻撃用の別ボタンや専用アクションはありません。

## 物理テンポ

物理更新は約33ms周期で進み、プレイヤー最大速度17、プレイヤー重力0.6、動態オブジェクト重力0.54、動態オブジェクト最大速度28へ調整しています。オブジェクトの速度減衰は軽めに保ち、フックで道具を振り回せる一方、麺の最大力を8へ下げて制御しやすくしています。プレイヤーとオブジェクトの上端は天井Y=40で止まり、天井抜け後に戻れなくなる状態を防ぎます。

## マップ

マップは現行比で横10倍・縦10倍に拡張した `18000 × 9800` の空間です。モードごとに専用レイアウトを持ち、同じマップを使い回しません。

| モード | マップ | 地形の特徴 |
|---|---|---|
| TAG | SAUCE LOOP | 周回足場、ゲート、追跡用の段差 |
| HIDE | PANTRY MAZE | 天井付きの部屋、縦壁、複数の分岐 |
| FREE | NOODLE PARK | 高低差のある自由な足場とゲート |
| HILL | PARMESAN PEAK | 上へ連続する階段状の登坂ルート |
| PVP | BONK BOULEVARD | 長い闘技場、仕切り、道具の散在 |

固定足場はモードごとに複数の段差・縦壁・狭い通路・囲い・分岐を組み合わせ、さらにseedで散在足場を追加します。描画はCanvasの円・線・矩形・多角形だけで構成し、外部画像素材に依存しません。スポーン地点もモード専用に分け、参加者は既存プレイヤーから180ワールド単位以上離れた空き地点を順に選びます。

ゲーム画面の右上には、固定地形を黄色、道具を赤、プレイヤーを色付きの点、現在の視界を枠線で示すミニマップを表示します。

## ローカル起動

```bash
cd server
npm install
npm start
```

ブラウザで `http://localhost:3000` を開きます。`http://localhost:3000/?demo` では、ルーム作成からゲーム開始までを自動実行します。


## Discord Activity

PASU.ioはDiscord Embedded App SDKに対応しています。Discord Activityとして起動すると、同じActivityインスタンスの参加者は、手動のルームコード入力なしで同じSocket.IOルームへ自動参加します。ホストがルーム画面で `START` を押すとゲームが開始します。通常のブラウザで起動した場合は、従来どおりルーム作成・4桁コード参加を利用できます。

### Activity向けローカル起動

```bash
cd server
pnpm install
pnpm run build:activity
npm start
```

Discord Developer PortalでActivityを有効化し、URL Mappingの `/` を公開HTTPSホストへ向けます。ローカル開発では、Discord公式のローカル開発手順に従ってHTTPSトンネルを利用するか、Application URL Overrideで開発URLを指定します。ローカルURL OverrideでSDKのClient IDを明示する場合は、次のように `client_id` を付けます。

```text
https://localhost:3000/?client_id=YOUR_DISCORD_APPLICATION_ID
```

本番のActivity URLは通常 `https://YOUR_DISCORD_APPLICATION_ID.discordsays.com/` となるため、ホスト名からClient IDを自動判定します。サーバーはSDKから取得した `instanceId` をルームキーとして扱い、同じDiscord Activityインスタンス内だけで参加者を共有します。Activity用のルーム上限は6人です。

Discord側の設定は、[Activities公式ドキュメント](https://docs.discord.com/developers/activities/overview)および[ローカル開発ガイド](https://docs.discord.com/developers/activities/development-guides/local-development)を参照してください。
