# Past.io

Past.ioは、パスタのキャラクターが麺を撃ち、地形・物体・他プレイヤーへ接続して動く横2DオンラインPvPプロトタイプです。勝利条件やHPはまだ持たせず、麺・地形・物体・プレイヤーの相互作用を検証します。

## 操作

| 入力 | 動作 |
|---|---|
| A / D | 地上で左右移動、麺接続中は振り子方向の操作 |
| マウス左ボタン長押し | カーソル方向へ麺を射出して対象へ接続。押している間だけ維持 |
| マウス移動 | 接続中の麺の方向を操作 |
| Esc / EXIT | ルームを退出 |

麺は固定地形、可動物体、他プレイヤーを別の接続対象として扱います。固定地形ではパスタ側が引かれ、可動物体では物体側が引かれ、プレイヤー接続では双方が干渉します。麺が対象へ届かなければ接続されません。

## ローカル起動

```bash
cd server
npm install
npm start
```

ブラウザで `http://localhost:3000` を開きます。

## マップ

画面内で完結する小さなアリーナではなく、横幅1800pxの一つの狭い工場空間を使用します。太い壁・床・天井、中央の煙突、上下の梁、細い通路、箱・ドラム・吊り荷を重ね、広い空白ではなく複数の接続候補と衝突箇所が連続する構造にしています。毎ルームのseedは、地形の基本配置とアリーナ識別を同期します。

## 仕様外にしているもの

HP、ダメージ、撃破、勝利条件、試合時間、武器、スキル、成長要素、リスポーン条件、ゴール到達条件は追加していません。まずは「麺を撃つ → 対象に接続する → 対象の種類に応じて物理挙動が変わる」をオンラインで操作できる状態にします。
